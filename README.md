# ТИШЕ. ЧЕЛОВЕК!

Браузерная 3D-стелс-игра по теме **Spider vs Human**. Ты — каракурт: спаси паучат на огромном столе, спрячься от руки человека и приведи семью в гнездо. Три главы, звук, сенсорное управление и локальные рекорды. Без регистрации, оплаты и установки для игрока.

## Поиграть локально

Нужен Node.js **22.12.0 или новее** (проверено на 22.23.2) и npm.

```text
npm ci
npm run dev
```

Открой адрес, который напечатает Vite (обычно http://127.0.0.1:5173). Уже запущенный dev-сервер не нужно запускать повторно.

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Движение | WASD, стрелки или клик по свободному месту | Джойстик слева или касание стола |
| Паутина-приманка | Пробел или кнопка | Кнопка «Паутина» |
| Камера | Q/E, перетаскивание правой кнопкой; C — сброс | Обзорное положение автоматически |
| Пауза | Esc, P или кнопка Ⅱ | Кнопка Ⅱ |

В главах 6/7/8 малышей. Человек замечает паука и направляет к нему кисть и предплечье; янтарная метка следует за целью. Мятные бумажные домики — безопасные укрытия и срывают наведение. Красный отпечаток ладони и пальцев фиксируется перед ударом. Уйди из него или отвлеки руку паутиной. Всего 3 сердца и 3 заряда; один заряд возвращается за 8 секунд. Малыши подбираются приближением. Гнездо принимает семью, только когда собраны все.

## Сборка и релиз

```text
npm run build
npm run preview
```

Публикуется **вся папка `dist`**, не исходники и не один index.html без assets. Все игровые ресурсы включены локально; CDN и внешние модели не нужны. Production не содержит диагностического интерфейса тестов. Открытие через `file://` не поддерживается: нужна HTML-страница на HTTP(S).

`npm run release` упаковывает готовый `dist` в `artifacts/quiet-human-web.zip` и пишет контрольные суммы в `artifacts/release-manifest.json`. Для упаковки нужен доступный Python 3 (проверено на 3.12.11); для игры он не нужен.

Для публикации выбран **GitHub Pages**. Workflow `.github/workflows/deploy-pages.yml` проверяет тесты, собирает игру и публикует только `dist` при push в `main` или ручном запуске. Используется отдельный репозиторий игры, не родительский репозиторий диска D:. В GitHub нужно выбрать **Settings → Pages → Source: GitHub Actions**; для бесплатного тарифа репозиторий должен быть публичным. Дополнительные секреты не нужны. **Публичный URL пока не подтверждён** — фактическая ссылка появится после успешного deploy. Инструкция: `docs/DEPLOYMENT.md`.

## Проверки

```text
npm test
npx playwright install chromium
npm run test:e2e
```

Для e2e сначала запусти `npm run dev`. Передай фактический адрес командой `node scripts/test-browser.mjs http://127.0.0.1:5174` (замени порт на напечатанный сервером); можно добавить путь или `--grep`. Альтернатива — переменная `GAME_URL` для `npm run test:e2e`. Кампания проверяется кликами и пробелом, без телепортации или искусственной победы; в третьей главе все восемь малышей дополнительно проверяются в кадре 390×844 с touch-controls. Состояние модели также проверяется отдельно без WebGL. Фактические результаты — `docs/QA_REPORT.md`.

После сборки: `node scripts/check-production.mjs <фактический preview URL>` проверяет релиз без dev-диагностики. После упаковки: `python scripts/verify-release.py` сверяет ZIP, весь состав dist, SHA-256 и актуальность локальных моделей/лицензий. `node scripts/verify-video.mjs` проверяет уже записанный ролик без повторного кодирования.

## Видео

`artifacts/quiet-human-30s.webm` — запись браузера длительностью 30 секунд, без звуковой дорожки; сам звук в игре есть. Это запись прежней версии: в ней ещё старые количество малышей и ориентация кисти, нового наведения нет; текущую правку она не подтверждает. Для пересоздания: dev-сервер должен работать, затем `npm run record`. Используется FFmpeg, поставляемый с Playwright; если его нет — `npx playwright install ffmpeg`. Разрешение ролика 960×720. `artifacts/video-report.json` содержит проверенную длительность и размер.

## Документы и архитектура

- `docs/PRODUCT_SPEC.md` — поведение и критерии приёмки для автора игры.
- `docs/TECH_SPEC.md` — состояние, данные, API модулей, рендер и ограничения.
- `docs/DECISIONS.md` — решения с основаниями.
- `docs/CODE_MAP.md` — карта модулей.
- `docs/QA_REPORT.md` — проверки и оставшиеся ограничения.

WebGL2 обязателен. При низкой частоте кадров игра снижает разрешение рендера. Прогресс хранится только в браузере: при очистке данных сайта рекорды исчезнут; при запрете хранилища сессия остаётся рабочей.

Кисть — локальная скелетная модель WebXR Input Profiles (MIT); паук — адаптированный Spider от sunburn (CC BY 3.0), восемь анимированных лап; паучата светлее и следуют цепочкой с коллизиями. Окружение, текстуры стола и звук созданы процедурно. Источники — `public/models/SOURCES.json`, лицензии — `public/THIRD_PARTY_LICENSES.txt` и `public/models/WEBXR-LICENSE.txt`. Three.js используется по MIT. Исходные документы конкурса сохранены в `rules/`.
