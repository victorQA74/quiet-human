# Публикация игры — GitHub Pages

## Текущий статус
Пользователь выбрал **GitHub Pages**. Настроен workflow `.github/workflows/deploy-pages.yml`. Локальная папка игры выделена в отдельный Git-репозиторий `D:/Development/Sharrowkin_game2`; родительский репозиторий `D:/` не используется для отправки. **Публичный URL пока не подтверждён: наличие workflow не означает, что игра уже опубликована.**

## Первая публикация
1. Отправь отдельный репозиторий игры в GitHub через Git-панель Sharrowkin. Если подключения нет, нажми **«Подключить GitHub»** и подтверди отправку только этой игры.
2. Новый репозиторий инструмент создаёт **приватным**. Для GitHub Free открой его на GitHub → **Settings → General → Danger Zone → Change repository visibility → Public**. Это делает исходники игры публичными. На тарифе с Pages для приватных репозиториев менять видимость не нужно. Не подключай платный тариф ради этой публикации.
3. Открой **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Открой **Actions → Deploy game to GitHub Pages → Run workflow → main → Run workflow**. Первый push может произойти до включения Pages; ручной запуск после настройки предусмотрен.
5. Дождись зелёных jobs **build** и **deploy**. Ссылка появится в environment `github-pages`, в итогах workflow и в **Settings → Pages**. Это источник фактического адреса; не считай предположительный `https://<владелец>.github.io/<репозиторий>/` уже работающим сайтом.

**Токены, SSH-ключи, пароли и дополнительные repository secrets для этого workflow не нужны.** Он использует встроенный `GITHUB_TOKEN` с минимальными разрешениями. Если Actions отключены политикой аккаунта или организации, включи разрешённые официальные `actions/*` либо обратись к администратору.

## Что делает автодеплой
- Запускается при push в `main` или вручную (`workflow_dispatch`).
- Использует Node.js 22.23.2 и `npm ci` с существующим `package-lock.json`.
- Выполняет `npm test`, `npm run build`, `node scripts/check-pages-build.mjs`.
- Проверяет наличие моделей/лицензий, локальных JS/CSS и путей, пригодных для размещения в подпапке репозитория.
- Публикует **только `dist/`** через официальные Pages actions. Исходники, документы, тесты и запись игры не входят в игровой сайт.
- Отдельный deploy-job получает `pages: write` и `id-token: write`; build-job не получает эти разрешения. Параллельные публикации сериализованы.

Относительный `base: './'` в Vite и загрузка GLB через `import.meta.env.BASE_URL` уже поддерживают проектный URL с подпапкой; название репозитория не зашивается в игровой код.

## Локальная проверка перед отправкой
```text
npm test
npm run build
node scripts/check-pages-build.mjs
npm run release
```
`npm run release` требует Python 3, создаёт `artifacts/quiet-human-web.zip` и manifest. GitHub Pages собирает сайт сам и не использует этот ZIP.

## Проверка опубликованной игры
Эти пункты выполняются **после** успешного deploy, не заменяются localhost-проверкой:
- HTTPS-страница открывается в приватном окне без логина и установки.
- JS/CSS, `models/hand.glb`, `models/spider.glb` и лицензии загружаются без 404 и запросов к localhost.
- Меню → обучение → игра: счётчик первой главы `0 / 6`; движение и подбор малыша работают.
- Паутина расходуется, человек отвлекается и направляет руку к пауку; ладонь направлена вниз.
- Пауза/продолжение работают. На телефоне видны джойстик, HUD и кнопка паутины; нет горизонтального скролла.
- После перезагрузки сохраняются настройки и прогресс при разрешённом localStorage.

Автоматический smoke: `node scripts/check-production.mjs <фактический HTTPS URL с завершающим />`. Проверка запускает Chromium, собирает настоящего малыша и сохраняет desktop/mobile-отчёт. Полное прохождение кампании она не заменяет.

## Граница публикации и файлы
Не отправляй весь диск, родительскую Git-историю, `node_modules`, `.asset-tools`, `.sharrowkin`, `.env`, ключи и raw-видео. Они исключены из отдельного репозитория; перед первым push проверяется его состав. `artifacts/` и `dist/` остаются локальными, игровые исходные GLB лежат в `public/models/` и нужны для CI.

Ссылки `http://127.0.0.1:...` доступны только на твоём компьютере и не подходят для сдачи. `artifacts/quiet-human-30s.webm` — запись прежней версии, её не выдаём за актуальную игру.

## Альтернатива без GitHub
Готовый `artifacts/quiet-human-web.zip` можно загрузить на itch.io как HTML-игру с отметкой **This file will be played in the browser**, размером 960×720, полноэкранным режимом и поддержкой мобильных устройств. Либо загрузи содержимое `dist/` на статический HTTPS-хостинг. В корне должны остаться `index.html`, `assets/`, `models/`, `favicon.svg`, `THIRD_PARTY_LICENSES.txt`.
